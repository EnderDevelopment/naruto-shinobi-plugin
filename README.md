# NarutoShinobi

NarutoShinobi is a Minecraft plugin that adds Naruto-themed abilities and items to your server. It includes powerful abilities like Rasengan, Chidori, and Shadow Clone, each with unique effects. Players can obtain scrolls for these abilities and use them in-game to enhance their gameplay experience.

## Install

1. Download the NarutoShinobi plugin JAR file from the [releases page](https://github.com/yourusername/NarutoShinobi/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Obtain the ability scrolls by using the in-game commands or by finding them in the world.
2. Right-click the scroll to activate the corresponding ability.
3. Enjoy the unique effects and powers provided by the NarutoShinobi plugin.
